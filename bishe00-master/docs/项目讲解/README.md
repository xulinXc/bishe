# 项目讲解文档索引

这个目录的文档是我为了向老师、答辩老师或指导老师讲清楚项目而整理的说明材料。它不是代码说明书，而是站在我自己的视角，把这个系统是怎么一步一步做出来的、为什么这样做、过程中遇到了什么问题、最后形成了什么结果，尽量完整地讲清楚。

如果老师想快速了解项目，可以按下面顺序阅读：

1. `01_项目是怎么一步步做出来的.md`
2. `02_系统现在到底做了什么.md`
3. `03_核心技术通俗解释.md`
4. `04_核心技术点逐个详细讲解.md`
5. `04_开发过程中遇到的问题和解决过程.md`
6. `05_我可以怎么向老师讲这个项目.md`
7. `项目讲解合集.md`

这些文档的特点：

- 以我的视角来写，不是纯技术报告口吻
- 尽量把技术点解释成人话，适合我自己复述
- 不只写“做了什么”，还写“为什么这样做”
- 把很多原来看起来零散的功能，串成一条完整故事线

我对这个项目的总体理解是：

这个系统不是单一的小工具，而是一个综合性的 Web 安全扫描与辅助分析平台。它最开始只是一个扫描功能的集合，后来在开发过程中不断加入目录扫描、POC 扫描、EXP 验证、Web 探针、WAF 绕过、JS 信息收集、AI 分析、MCP 集成等能力，逐渐变成一个可以完成“从信息收集到漏洞验证再到结果分析”的完整系统。

从工程实现上看，这个系统当前主要由三部分组成：

1. 前端页面，用来输入参数、发起扫描、实时展示结果
2. Go 后端服务，用来执行各种扫描任务和调度流程
3. 外部能力集成，包括 AI 接口、Python 脚本执行、逆向工具 MCP、外部扫描工具等

我写这些文档的目的，不是为了把自己说成所有技术都很懂，而是为了把项目做出来的真实过程讲清楚：

- 我一开始的目标是什么
- 我是怎么把功能一点点加上去的
- 为什么中间会显得很乱
- 最后哪些功能真正留了下来并组成了系统主线
- 我虽然很多代码借助了 AI，但我已经把系统结构、模块关系、功能作用和关键技术点重新梳理明白了

这套文档可以直接作为：

- 毕业设计讲解材料
- 开题或中期检查时的项目说明
- 论文“系统设计与实现”章节的素材来源
- 答辩前的自我梳理笔记
