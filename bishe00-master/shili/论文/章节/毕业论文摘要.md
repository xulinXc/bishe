# 毕业论文摘要

随着业务快速向 Web 与移动应用迁移，公开端口暴露、弱鉴权接口、第三方组件缺陷以及前端打包资源中隐藏接口等风险持续增多。传统安全工具往往聚焦单点能力，端口探测、目录枚举、POC 验证、EXP 利用、前端资源收集与反编译分析之间缺少统一任务调度与数据回流机制，导致扫描结果分散、复现链条冗长、证据沉淀困难。同时，在攻防演练与实验教学场景中，还需要兼顾实时反馈、可审计性与资源隔离等工程要求。

针对上述问题，本文设计并实现了一个轻量一体化安全扫描平台 NeonScan 2.0。平台采用 Go 1.21 单进程 HTTP 服务架构，前端采用静态 HTML、CSS 与 JavaScript 多页面模式，后端通过统一的“任务 + SSE 事件流”机制管理长耗时扫描任务。系统集成端口扫描、目录扫描、POC 扫描、EXP 执行、Web 指纹探测、WAF 绕过、JS/API 资产收集、JADX MCP 会话分析等能力，并将 FFUF、URLFinder、Packer-Fuzzer 等外部工具纳入统一的数据流。平台兼容 Legacy、X-Ray 与 Nuclei 子集三种 POC 规则格式，支持多步骤 EXP 编排、变量提取与 Cookie 贯穿。

在 2.0 版本中，系统进一步引入 AI 自动扫描编排、AI 生成 Python EXP、批量生成 EXP、POC 结果归一化为 ExpSpec、自动验证与迭代修正等关键能力，形成“资产发现—漏洞验证—EXP 生成—自动验证—报告汇总”的闭环流程。平台通过统一 AI Provider 抽象兼容 DeepSeek、OpenAI、Anthropic 与 Ollama；通过 JADX MCP 会话管理实现 APK 反编译辅助分析；通过上传目录隔离、7 天自动清理与前端 localStorage 状态持久化提高系统可维护性与可审计性。实验结果表明，该平台能够有效缓解工具碎片化与流程割裂问题，提升漏洞验证效率与结果复现能力，具备较好的工程实用价值。

**关键词**：网络安全扫描；漏洞验证；任务编排；MCP 协议；AI 安全分析
